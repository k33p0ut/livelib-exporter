# livelib-exporter

Небольшая консольная утилита для резервного копирования **публичного** списка прочитанных книг пользователя LiveLib. Экспортирует авторов, названия, оценки, даты чтения и доступные публичные метаданные в CSV и JSON.

Проект не связан с LiveLib и не использует официальный API. Он обращается к внутреннему публично доступному endpoint новой версии сайта, поэтому совместимость может измениться без предупреждения.

Экспортёр учитывает особенность текущей пагинации LiveLib: сайт может вернуть ссылку вида `/api/...`, хотя рабочий маршрут находится под `/trisolaris/api/...`. Такая ссылка безопасно нормализуется перед следующим запросом.

## Возможности

- никнейм **или числовой LiveLib ID** как единственный обязательный аргумент;
- автоматическое определение внутреннего числового ID для никнейма;
- прямой экспорт по числовому ID без обращения к странице `/reader/...`;
- загрузка всех страниц с ограничением от зацикливания;
- повтор запросов при `429` и временных серверных ошибках;
- поддержка `Retry-After` как в секундах, так и в формате HTTP-даты;
- CSV в `UTF-8 with BOM`, удобно открывающийся в Excel;
- нормализованный JSON с версией схемы;
- отдельные оценки `rating_5` и `rating_10`;
- сохранение точности даты: день, месяц, год или отсутствие даты;
- безопасное разделение `read_date` и технической даты `status_set_at`;
- опциональное удаление дубликатов без потери данных по умолчанию;
- атомарная запись файлов: незавершённый экспорт не повреждает старый файл;
- библиотечный Python API и тестируемый HTTP-клиент;
- никаких обязательных сторонних зависимостей.

## Требования

Python 3.10 или новее.

## Установка

```bash
python -m pip install .
```

Для разработки:

```bash
python -m pip install -e ".[dev]"
```

Без установки можно запустить локальный файл:

```bash
python livelib_export.py nickname
```

Или передать числовой LiveLib ID напрямую:

```bash
python livelib_export.py 121955
```

Если первый аргумент состоит только из цифр, он автоматически считается ID пользователя, а не никнеймом.

## Использование

```bash
livelib-export nickname
livelib-export 121955
```

Сохранить в другую папку:

```bash
livelib-export nickname --output-dir exports
```

Сохранить также исходные ответы API:

```bash
livelib-export nickname --raw
```

Использовать дату установки статуса только как запасную вычисленную дату:

```bash
livelib-export nickname --fallback-to-status-date
```

При этом:

- `read_date` останется пустым;
- `effective_read_date` получит дату из `status_set_at`;
- `effective_date_source` будет равно `status_set_at`.

Создать стабильные имена файлов для регулярного резервного копирования:

```bash
livelib-export nickname --no-timestamp --overwrite
```

Сортировка нормализованного экспорта:

```bash
livelib-export nickname --sort read-date
livelib-export nickname --sort title
```

По умолчанию сохраняется исходный порядок LiveLib.

## Поля оценок

- `rating_raw` — значение, полученное от LiveLib без смыслового преобразования;
- `rating_5` — нормализованная оценка по пятибалльной шкале;
- `rating_10` — та же оценка, умноженная на два.

Нулевое или отсутствующее значение не превращается в оценку: соответствующие поля остаются пустыми.

## Даты

- `read_date` — дата, явно указанная пользователем;
- `date_precision` — `day`, `month`, `year` или `none`;
- `status_set_at` — исходное время изменения статуса;
- `status_set_date` — календарная часть технического времени;
- `effective_read_date` — дата для последующей обработки;
- `effective_date_source` — источник вычисленной даты.

Техническая дата статуса **не выдаётся за дату чтения без явного флага**.

## Python API

По никнейму:

```python
from pathlib import Path

from livelib_exporter import ExportOptions, export_profile

result = export_profile(
    "nickname",
    options=ExportOptions(
        output_dir=Path("exports"),
        fallback_to_status_date=False,
        sort_by="source",
    ),
)

print(result.paths)
```

По числовому ID без загрузки HTML-профиля:

```python
result = export_profile(
    "121955",
    user_id=121955,
    profile_identifier_type="user-id",
    options=ExportOptions(output_dir=Path("exports")),
)
```

Для тестов или нестандартной среды можно внедрить собственный opener, sleeper и endpoints через `LiveLibClient`.

## Безопасность и этика

- Используйте только публичные профили и данные, к которым у вас есть законный доступ.
- Не уменьшайте задержку между страницами без необходимости.
- Не запускайте массовый сбор профилей.
- `--raw` может сохранить заметки и другие публично возвращаемые поля. Проверяйте файл перед публикацией.
- Никакие логины, пароли или cookies инструменту не нужны.

## Идентификатор профиля в JSON

Начиная с версии 1.1 экспорт содержит:

- `profile_identifier` — исходный никнейм или числовой ID;
- `profile_identifier_type` — `nickname` или `user-id`;
- `username` — никнейм либо `null`, если экспорт запускался только по ID;
- `livelib_user_id` — подтверждённый числовой ID;
- `source` — страница профиля для никнейма или API-адрес для числового ID.

## Ограничения

Внутренний endpoint LiveLib недокументирован. Если сайт изменит HTML профиля, адрес API или структуру JSON, потребуется обновление экспортёра. Перед массовым использованием проверьте один небольшой публичный профиль.
